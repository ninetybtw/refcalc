# Кошелёк судьи

Веб-приложение (PWA) для хоккейных судей: учёт игр по лигам, авторасчёт ставки по категории, амплуа и году рождения, отметка «деньги получены», итоги по месяцам и за всё время, админ-панель.

Один и тот же код запускается двумя способами:
- **A. Cloudflare Workers + D1.** Бесплатно, без своего сервера. ⚠️ Из России без VPN работает плохо: провайдеры режут Cloudflare до 16 КБ.
- **B. Свой сервер (VPS) на Node.js.** Данные лежат в одном файле SQLite. Нормально открывается из России, если сервер российский.

---

## Вариант A — Cloudflare (бесплатно)

Нужны Node.js 22+ и бесплатный аккаунт на cloudflare.com.

```bash
npm install
npx wrangler login                       # откроется браузер, войдите в Cloudflare
npx wrangler d1 create referee-pay       # создаст базу и покажет database_id
```
Скопируйте `database_id` из вывода в `wrangler.toml` вместо `ВСТАВЬТЕ_СЮДА_ID_БАЗЫ`. Затем:

```bash
npm run db:remote                        # создать таблицы
npx wrangler secret put INVITE_CODE      # (необязательно) код приглашения для регистрации
npm run deploy                           # выдаст адрес https://referee-pay.<ваш-ник>.workers.dev
```

Обновить приложение после правок: `npm run deploy`.
Локальная проверка: `npm run db:local && npm run dev` → http://localhost:8787

## Вариант B — свой сервер (VPS)

Нужен Node.js 22.5+ (в нём уже встроен SQLite, ничего ставить не надо).

```bash
npm install --omit=dev
INVITE_CODE=hockey PORT=3000 DB_FILE=/var/lib/kosh/data.db npm start
```

Телефонам нужен HTTPS, иначе вход не сохранится. Проще всего поставить перед приложением Caddy: он сам выпустит сертификат. `/etc/caddy/Caddyfile`:
```
судьи.ваш-домен.ru {
    reverse_proxy localhost:3000
}
```
Для автозапуска подойдёт systemd или `pm2 start "npm start"`.
**Бэкап**: копируйте файл `data.db`, в нём все данные.

## Первый запуск

1. Откройте адрес приложения и зарегистрируйтесь. **Первый зарегистрированный пользователь автоматически становится админом.**
2. Скиньте ссылку коллегам (и код приглашения, если вы его задали).
3. На телефоне: Safari → «Поделиться» → «На экран Домой»; Android/Chrome → меню → «Установить приложение».

## Как считается ставка

Лиги и ставки меняются в **Профиль → Админ-панель → Лиги и ставки**, код трогать не нужно.

Каждая лига — это список правил «амплуа + категории + возраст → ставка». Берётся первое подходящее правило сверху вниз. Пустое поле означает «любое». Если не подошло ни одно правило, судья вводит сумму вручную.

**Возраст** считается из года рождения и сезона игры: новый сезон начинается 1 июля. Пример для сезона 2026/27: 2009 г.р. = до 18, 2010 = до 17, … 2015 = до 12. На следующий сезон всё пересчитается само.

Флажки лиги:
- **Спрашивать год рождения** — в форме появится выбор года;
- **Год не влияет на ставку** — год записывается, но в расчёте не участвует (как в «Игре турнира»);
- **Свободная форма** — судья сам пишет название, амплуа и сумму (как в «Другом»);
- **Показывать** — снимите, чтобы скрыть лигу и при этом не трогать старые игры.

Ставки по умолчанию лежат в `src/leagues.js`. Кнопка «Сбросить» в админке возвращает их.

## Пароли

- Пароли хранятся в базе в виде хеша (PBKDF2), открытым текстом их не видит никто, включая админа.
- При регистрации судье один раз показывается **код восстановления**. По нему можно сбросить пароль самому: «Забыл пароль» на экране входа.
- Админ может выдать судье временный пароль: Админ-панель → Судьи → «Сбросить пароль».
- Админ не видит, сколько зарабатывают коллеги: в админке видны только число игр и дата последней.

